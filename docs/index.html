macOS 未署名ビルドの初回起動について

GitHub Actions でビルドされた macOS 版は現在コード未署名のため、/Applications へコピー後の初回起動時に「壊れているため開けません」と表示される場合があります。ターミナルで以下のコマンドを実行して隔離属性（quarantine）を解除してください。

xattr -cr /Applications/Conductor.app

※ 隔離属性のみを削除したい場合は xattr -dr com.apple.quarantine /Applications/Conductor.app でも同様に起動できます。

ソースからビルド・起動する

Node.js 22+・pnpm・Git 2.25+ と、いずれかの CLI（codex / agy / claude）があればローカルで即座に開発モード起動できます。
